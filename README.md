\## 📌 Project Overview



This project focuses on building a multi-page website through team collaboration using Git and GitHub.



Our team divided the development tasks among members, created individual branches, committed and pushed changes, reviewed pull requests, and merged code into the main branch.



We also practised identifying and resolving merge conflicts through team discussions and successfully hosted the completed website using GitHub Pages.



\## 🎯 Project Objectives



\- Gain practical experience with Git commands and version control.

\- Understand branch creation and collaborative development.

\- Work with a shared GitHub repository.

\- Practise pull requests and code reviews with two approvals.

\- Identify and resolve merge conflicts through team discussions.

\- Host the completed website using GitHub Pages.

\### 🔄 GitHub Collaboration Workflow



Our project followed this workflow:



1\. Clone the common repository.

2\. Create an individual branch.

3\. Develop the assigned web page.

4\. Stage and commit changes.

5\. Push changes to GitHub.

6\. Create a pull request.

7\. Perform code reviews and obtain two approvals.

8\. Resolve merge conflicts through team discussions, if required.

9\. Merge approved changes into the main branch.

10\. Publish the website using GitHub Pages.



💻 Git Commands Practised



| Git Command | Purpose |

|---|---|

| `git clone <repository-url>` | Clone the remote repository |

| `git branch` | List available local branches |

| `git switch -c <branch-name>` | Create and switch to a new branch |

| `git status` | Check repository status |

| `git add .` | Stage modified files |

| `git commit -m "message"` | Commit changes |

| `git push -u origin <branch-name>` | Push branch to GitHub |

| `git pull` | Fetch and integrate remote changes |



\### ⚠️ Merge Conflict Resolution



During the project, we intentionally created a merge conflict in the shared `style.css` file to gain practical experience.



\*\*Our conflict-resolution approach:\*\*



\- Identified the conflicting changes.

\- Reviewed both versions of the CSS code.

\- Discussed the issue during a team meeting.

\- Collaboratively selected the correct code.

\- Removed conflict markers and verified the updated file.

\- Reviewed the final changes before merging.
